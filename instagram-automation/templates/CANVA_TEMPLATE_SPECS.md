# NUBEAUX Collective - Canva Template Specifications

Create these 10 templates in Canva Pro for your Instagram content system.

---

## Brand Guidelines

### Colors
| Name | Hex | Usage |
|------|-----|-------|
| Charcoal | #1a1a1a | Primary backgrounds, text |
| Bone | #faf8f5 | Light backgrounds |
| Ecru | #f5f1eb | Secondary light backgrounds |
| Terracotta | #c2703e | Accent color, CTAs, highlights |
| Gold | #b8953f | Premium accents, stats |
| Warm Grey | #8a8278 | Secondary text |
| White | #ffffff | Text on dark backgrounds |

### Typography
| Element | Font | Weight | Notes |
|---------|------|--------|-------|
| Headlines | Playfair Display | Regular/Medium | Elegant, editorial |
| Subheads | Playfair Display | Italic | For emphasis |
| Body | Inter | Regular | Clean, modern |
| Stats/Numbers | Playfair Display | Medium | Large, impactful |
| Labels | Inter | Medium | Uppercase, small |

### Logo Placement
- NC emblem in bottom-right corner
- White on dark backgrounds
- Charcoal on light backgrounds
- Size: ~40px on 1080x1080

## Canva Pro Tips

1. **Brand Kit:** Set up your colors and fonts in Canva's Brand Kit for easy access
2. **Folders:** Create a "NUBEAUX Templates" folder to keep templates organized
3. **Naming:** Name templates clearly: "NC - Stat Post", "NC - Carousel Cover", etc.
4. **Duplicate:** Always duplicate a template before editing for a new post
5. **Export:** Export as PNG for best quality, JPG for smaller file size
